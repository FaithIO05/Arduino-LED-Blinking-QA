# Arduino LED Blinking - AI-Assisted QA

## 1. Project Overview
This project demonstrates LED blinking using an Arduino-compatible
microcontroller. It also explores AI-assisted code review,
quality assurance, bug tracking, and code improvement using GitHub.

## 2. Objective
- Implement a basic LED blinking program.
- Use AI tools to review code and identify potential bugs.
- Document QA issues using GitHub Issues.
- Record code fixes and their verification results.

## 3. Hardware Requirements
- Arduino Uno or compatible board
- LED (optional external LED)
- 220-ohm resistor (for an external LED)
- Jumper wires and USB cable, if required

## 4. Software and Tools
- Arduino IDE
- GitHub
- ChatGPT or another AI coding assistant

## 5. Source Code
The file `led_blink.ino` contains the Arduino LED blinking program.
It configures digital pin 13 as an output and repeatedly turns
the LED on and off at one-second intervals.

## 6. Quality Assurance
Potential code issues will be investigated using AI-assisted review.
Findings, root causes, fixes, and verification evidence will be
documented through GitHub Issues and project records.

## 7. Project Status
Initial source code committed. QA analysis and verification are pending.
